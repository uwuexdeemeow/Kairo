# The app ring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A shortcut-opened dial of seven segments at the pointer, turned or dragged to pick.

**Architecture:** A pure Rust model (`ring/mod.rs`) with its TypeScript twin; a native Direct2D layered popup on Windows; a transparent web window elsewhere; two global shortcuts told apart.

**Tech Stack:** Rust (windows crate, Direct2D/DirectWrite), TypeScript, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-04-app-ring-design.md`

## Global Constraints

- Default shortcut `Alt+Q`; window 300×210; neighbours at 0.5 and 0.22 opacity; tap window 200 ms; drag threshold 4 px; turn animation 140 ms.
- Segment order: chrono, ledger, palette, dashboard, task, note, focus.
- No new dependencies.

## Review Focus

- The two shortcuts never both fire one action; changing one never drops the other.
- The ring never opens off-screen (multi-monitor, negative coordinates).
- Holding the modifier while the ring takes focus: the release is still seen.
- Strict mode and a running session refuse Focus 25 without closing silently.
- The ring's window is freed after closing (no web view or D2D resources left).
